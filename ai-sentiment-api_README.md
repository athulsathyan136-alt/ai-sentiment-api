# 🧠 AI Sentiment Analyzer API

An end-to-end Artificial Intelligence project that analyzes text and predicts its sentiment using a pre-trained NLP model.

The application is built with Python, Hugging Face Transformers, FastAPI, and Docker.

---

## 🚀 Features

- 🧠 AI-powered sentiment analysis
- 🤗 Pre-trained Transformer model
- ⚡ FastAPI REST API
- 📖 Interactive Swagger UI
- 🛡️ Input validation
- ❤️ Health check endpoint
- 🐳 Docker support
- 🐙 GitHub-ready project structure

---

## 🛠️ Technologies

- 🐍 Python
- 🤗 Hugging Face Transformers
- 🔥 PyTorch
- ⚡ FastAPI
- 🚀 Uvicorn
- 🐳 Docker
